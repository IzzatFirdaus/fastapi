# FastAPI

A lightweight RESTful API built with Python and FastAPI demonstrating core backend development concepts, clean route structuring, and interactive API documentation.

## Features
- **FastAPI Framework:** Asynchronous high-performance web framework.
- **Data Validation:** Strict type enforcement using Pydantic.
- **Interactive Documentation:** Automatic OpenAPI Swagger UI generated at \/docs\.

## Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/IzzatFirdaus/fastapi.git
   cd fastapi
   ```

2. **Create and activate virtual environment:**
   ```powershell
   py -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run development server:**
   ```bash
   fastapi dev main.py
   ```

5. Access interactive API docs at \http://127.0.0.1:8000/docs\.
